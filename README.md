# 🏥 รายงานโครงการ: ระบบสารสนเทศและจัดการเว็บไซต์สำนักงานสาธารณสุข (Hospital CMS)

**วันที่แก้ไขล่าสุด:** 02/06/2026

---

## 1. บทนำ (Introduction)
โครงการนี้ได้รับการปรับปรุงและพัฒนาขึ้นเพื่อเป็นระบบเว็บไซต์ประชาสัมพันธ์และระบบบริหารจัดการข้อมูลหลังบ้าน (Back-office) สำหรับสำนักงานสาธารณสุขหรือหน่วยงานอุตสาหกรรมสุขภาพ โดยได้รับการออกแบบโครงสร้าง UI/UX และธีมสีใหม่ทั้งหมดให้เป็นสไตล์ **Premium Glassmorphism** ที่มีความเรียบหรู ทันสมัย โหลดหน้าเว็บได้อย่างรวดเร็ว และแสดงผลได้สมบูรณ์แบบบนทุกขนาดหน้าจอ (Responsive Design)

---

## 2. วัตถุประสงค์ (Objectives)
1. **การจัดลำดับเนื้อหาที่เป็นเลิศ (Visual Hierarchy):** ปรับปรุงโครงสร้างหน้าแรกเพื่อนำเสนอข้อมูลสำคัญแก่ประชาชนได้ในทันทีโดยไม่ต้องเลื่อนหน้าจอลงลึก (Reduce Scrolling)
2. **ความงามและเอกลักษณ์เฉพาะตัว (Premium Aesthetics):** เปลี่ยนการออกแบบจากเทมเพลตทั่วไปให้เป็นระบบกระจกฝ้าโปร่งแสง (Glassmorphism) ร่วมกับระบบฟอนต์คู่คัดสรรอย่าง Sarabun และ Outfit
3. **ระบบจัดการเนื้อหาประสิทธิภาพสูง (Robust CMS):** ช่วยให้เจ้าหน้าที่สามารถอัปโหลดประชาสัมพันธ์ ข่าวจัดซื้อจัดจ้าง เอกสารดาวน์โหลด และระบบผู้บริหารได้โดยไม่ต้องมีความรู้ด้านการโค้ด
4. **ระบบความปลอดภัยระดับสากล (Security):** เสริมความปลอดภัยขั้นสูงสุดด้วยระบบยืนยันตัวตน 2 ขั้นตอน (2FA) และสแกน QR Code ผ่านแอป Google Authenticator

---

## 3. ขอบเขตและสถาปัตยกรรมของระบบ (System Scope & Architecture)

### 3.1 ส่วนหน้าเว็บไซต์ (Frontend UX/UI)

ระบบได้รับการปรับปรุงโครงสร้างเลย์เอาต์ (Layout Reorganization) ใหม่ทั้งหมดเพื่อลบจุดบกพร่องดั้งเดิม:

* **หน้าแรก (Homepage Layout):**
  * **แบนเนอร์สไลด์ขนาดกะทัดรัด (Compact Widescreen Banner):** ปรับขนาดแบนเนอร์สไลด์ให้กระชับ เพื่อป้องกันการบดบังและผลักเนื้อหาสำคัญตกขอบล่างของหน้าจอ
  * **ศูนย์ข่าวสารและบริการ (Announcements Tabs) [Above the Fold]:** ย้ายส่วนประกาศข่าวสาร (ทั่วไป, ดาวน์โหลด, จัดซื้อจัดจ้าง, ITA) จากด้านล่างสุดของหน้าจอขึ้นมาเป็นพระเอกหลักของหน้าเว็บ อยู่ด้านบนเคียงข้างกับทำเนียบผู้บริหารและเมนู เพื่อให้ประชาชนเข้าถึงข้อมูลหลักได้ในทันที
  * **ข่าวสารกิจกรรมประชาสัมพันธ์ (PR Activities Gallery):** ปรับโครงสร้างเลย์เอาต์แกลเลอรีภาพกิจกรรมเป็นแบบ Grid แนวนอนเต็มสัดส่วนอยู่ใต้เนื้อหาหลัก จัดวางด้วยสัดส่วนกระดาษ A4 สวยงามเป็นระเบียบ
  * **แผงวิดเจ็ตส่วนล่างแบบ 3 คอลัมน์ (Bottom Widgets Panel):** ย้ายวิดเจ็ตที่เป็นเนื้อหาเสริม เช่น รายชื่อหน่วยงานในสังกัด, สถิติผู้เข้าชมเว็บไซต์ และแผนที่ติดต่อออกจากแถบเมนูด้านซ้าย เพื่อให้แถบซ้ายสั้นกระชับน่าอ่าน แล้วนำมาจัดเรียงในแผง 3 คอลัมน์แนวนอนที่สวยงามด้านล่างสุดเหนือก้นเว็บ (Footer)
* **หน้าดูประกาศหลัก (Quiet News Reader - `announcement.php`):**
  * ปรับแต่งหน้าข่าวสารให้เรียบร้อยและสงบตาขึ้น (Quieter Design) โดยการเชื่อมโยงระบบสไตล์ซีตหลัก (`index.css`)
  * ปลี่ยนเมนูบาร์เดิมที่เป็นสีไล่ระดับเขียวทึบ (Solid Gradient) มาเป็น **Glassmorphism Navbar** โปร่งแสง
  * ลบองค์ประกอบรกสายตาและสีส้มแสดผิดธีม (`#fff3e0`) ของหัวข้อกลุ่มข่าวในเมนูข้างออก และแทนที่ด้วยธีมสีเขียวพาสเทลโปร่งแสงที่กลมกลืนกับองค์กร
* **หน้าเนื้อหาอิสระ (Quiet Custom Pages - `page.php`):**
  * ยุบเลิกการเขียนโค้ด CSS ซ้ำซ้อนภายนอก และจัดระเบียบคอลัมน์และเมนูลิงก์ด้านข้างใหม่ทั้งหมด
  * ลบเส้นขอบข้างสีทึบหนา 5px (Side-stripe border) ที่ขัดกับดีไซน์สากลออก เพื่อให้การแสดงผลเมนูข้างเรียบร้อยเป็นธรรมชาติ
* **ระบบเมนูบนมือถือ (Mobile Responsive Overlay):**
  * เพิ่มปุ่ม Hamburger Menu ที่รองรับการสไลด์เปิด-ปิดเมนูบนหน้าจอมือถือได้อย่างลื่นไหล ป้องกันไม่ให้แถบนำทางทับซ้อนกับแบนเนอร์สไลด์

### 3.2 ส่วนหลังบ้านผู้ดูแลระบบ (Backend Admin Panel)
* **Dashboard & First-Run Experience:** ปรับปรุงหน้าข้อมูลและสถิติให้มีสไตล์พรีเมียม สวยงาม ลบความเป็นหน้าตาที่ดูสร้างโดย AI ออกอย่างสิ้นเชิง มีไอคอนสะท้อนฟังก์ชันงานจริง
* **จัดการข้อมูลหน่วยงาน:** แก้ไขชื่อ, โลโก้แบรนด์, ลิงก์ช่องทางติดต่อด่วน, การกำหนดธีมสีแบรนด์
* **จัดการเนื้อหา (CMS Module):** แก้ไขข้อมูลภาพแบนเนอร์สไลด์, แผงรายชื่อผู้บริหาร, ระบบอัปโหลดเอกสารแนบประกอบประกาศ
* **ระบบสร้างหน้าเว็บอิสระ (Custom Page Builder):** สำหรับสร้างหน้าเว็บไดนามิกเพิ่มเติม (พันธกิจ, นโยบาย) พร้อมระบบสร้างลิงก์เข้ารหัสความปลอดภัย (Obfuscated Links) ป้องกันการสแกนช่องโหว่

### 3.3 ระบบความปลอดภัยระดับองค์กร (Security Engine)
* **Google OAuth 2.0:** บริการเข้าสู่ระบบผ่านบัญชี Google (Gmail) สำหรับเจ้าหน้าที่
* **Auto-Provisioning:** ระบบลงทะเบียนเจ้าหน้าที่รายใหม่เข้าสู่ระบบอัตโนมัติเมื่อทำการยืนยันตัวตนผ่าน Google สำเร็จครั้งแรก
* **Two-Factor Authentication (2FA):** เสริมความปลอดภัยอีกชั้นด้วยรหัส OTP 6 หลักผ่านแอป Google Authenticator บังคับใช้กับผู้ใช้งานทุกคนเพื่อป้องกันรหัสผ่านรั่วไหล
* **Role-Based Access Control (RBAC):** แบ่งแยกการทำงานตามระดับสิทธิ์ (Super Admin และ Admin ทั่วไป)

## 4. เครื่องมือและเทคโนโลยีหลักที่ใช้ (Technologies & Architecture)
* **ภาษาหลักของระบบ:** PHP 7.4 ขึ้นไป / PHP 8.x
* **ระบบฐานข้อมูล:** MySQL / MariaDB (ใช้มาตรฐานการดึงข้อมูลแบบ PDO เพื่อป้องกัน SQL Injection)
* **ฝั่งหน้าเว็บ (Frontend UI):**
  * **สไตล์และเฟรมเวิร์ก:** Vanilla CSS3 (Custom Glassmorphic Variables) ร่วมกับสัญรูป FontAwesome 6
  * **ฟอนต์หลัก:** Google Fonts (Outfit สำหรับป้าย หัวข้อภาษาอังกฤษ และ Sarabun สำหรับการอ่านเนื้อหาภาษาไทยที่สบายตา)
  * **ระบบแอนิเมชัน:** AOS (Animate On Scroll) เวอร์ชัน 2.3.1 ควบคุมการเคลื่อนไหวอย่างสมูทหรูหรา
* **ห้องสมุดภายนอก (Libraries & API Integration via Composer):**
  * `google/apiclient`: ระบบ Google Login Core API
  * `sonata-project/google-authenticator`: ระบบจัดการและถอดรหัส Key สำหรับ 2FA
  * `goqr.me API`: บริการสร้าง QR Code ด่วนแบบไร้ลายน้ำ

## 5. แผนผังโครงสร้างโฟลเดอร์โครงการ (Project File Structure)
* `assets/css/index.css` — หัวใจระบบดีไซน์หลัก (สี, แอนิเมชัน, เมนู, ปุ่ม, ก้นเว็บ)
* `index.php` — หน้าแรกของเว็บไซต์ (ระบบจัดวาง Announcements ไว้บน และ PR Activities แนวนอนไว้ล่าง)
* `announcement.php` — หน้าอ่านข่าวประกาศ (ดีไซน์ใหม่เรียบหรู คลีนสะอาดตา เชื่อมโยง CSS หลัก)
* `page.php` — หน้าแสดงข้อมูลอิสระ (เลย์เอาต์คอลัมน์คลีนสะดุดตา ลบปุ่มขอบหนา)
* `db_connect.php` & `config.php` — ระบบเชื่อมต่อฐานข้อมูลแบบ PDO ปลอดภัยสูง
* `admin/` — โมดูลหลังบ้านและโมดูลยืนยันตัวตน Google Login & 2FA
* `admin/pages/dashboard.php` — แผงควบคุมสถิติหลังบ้านสไตล์พรีเมียม
